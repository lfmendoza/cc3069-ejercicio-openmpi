# Evidencias de ejecución

Capturas reales de compilación y ejecución con GCC 13.3.0 y Open MPI 4.1.6 en Linux.

- 01_original_gather.png: Gather original.
- 02_original_reduce.png: Reduce original.
- 03_modificado_gather.png: Gather con dos temperaturas.

Las líneas locales pueden aparecer en distinto orden por la ejecución concurrente. Gather conserva el orden por rank.
